На сцене есть игрок и несколько врагов
Игрок:
-	Имеет HP.
-	Двигается по плейну через WASD / стрелки.
-	Стреляет по клику мыши.
-	Переключает оружие кнопками 1, 2, 3, 4.

Оружие:
-	Пистолет.
-	Дробовик/ружье с двумя стволами.
-	Автомат.
-	Электрошокер
  
Параметры оружия:
-	Урон
-	Скорострельность
-	Дальность
-	Разброс
-	Время перезарядки
-	Размер обоймы
Стрельба снарядами-сферы Unity

Враги:
-	Имеют HP.
-	Могут двигаться.
-	Получают случайное оружие из доступных.
-	Атакуют игрока в зоне видимости.
-	Не стреляют чаще, чем позволяет их оружие.
